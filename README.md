# Портфолио RomanovIT

Статический сайт: HTML + CSS + JS, без сборщиков. Откройте `index.html` двойным кликом.

## Как добавить видео

1. Положите исходник в папку `для сайта/`.
2. Добавьте строку в `content/videos.json`:
   ```json
   { "file": "new.mp4", "category": "reels", "tags": ["2d"], "market": "us",
     "title": { "ru": "Название", "en": "Title" } }
   ```
   - `category`: `reels` | `youtube` | `edits` | `ai`
   - `tags` (необязательно): `2d`, `3d` — дополнительные фильтры
   - `market: "us"` — бейдж «US» на плитке
   - `previewStart` (необязательно) — с какой секунды резать превью
   - Порядок строк = порядок в сетке.
3. Запустите:
   ```
   node scripts/build.mjs
   ```
   Скрипт (нужен ffmpeg) сожмёт видео до 1080p → `media/full`, нарежет 5-секундные превью → `media/preview`,
   постеры → `media/poster` и обновит `js/videos.js`. Уже готовые файлы пропускаются; `--force` пересоберёт всё.

Категория-фильтр появляется на сайте автоматически, когда в ней есть хотя бы одно видео.

## Телефон на первом экране

В телефоне листаются первые 3 вертикальные работы из `content/videos.json` (их превью). Порядок = порядок в json.

## Кольцо инструментов

Список логотипов — массив `TOOLS` в `js/main.js`. Иконки лежат в `assets/logos/` и собраны в `js/logos.js`.

## Структура

```
index.html            страница
css/style.css         стили (цвета — переменные в :root)
js/i18n.js            тексты RU / EN
js/main.js            masonry-сетка, превью, фильтры, лайтбокс
js/videos.js          генерируется скриптом — вручную не править
content/videos.json   список работ
scripts/build.mjs     подготовка видео
для сайта/            исходники (на хостинг НЕ загружать)
media/                готовые видео для сайта
```

## Публикация

На хостинг загружаются всё, **кроме** `для сайта/`, `scripts/`, `content/`, `.claude/`.
Бесплатно: Netlify (перетащить папку на app.netlify.com/drop) или Vercel.
Если видео станет много — полные версии лучше перенести на Bunny Stream / Kinescope.

## SEO

- Тексты сайта (RU/EN), цены и вопросы — `js/i18n.js`. Цифры цен для микроразметки — `PRICE_RUB` в `scripts/build.mjs`.
- После правок текстов или видео запустите `node scripts/build.mjs`: он впишет русские тексты и список работ прямо в `index.html`
  (их видит поисковик без JavaScript), обновит микроразметку schema.org, `sitemap.xml` и `robots.txt`.
- Адрес сайта — `SITE_URL` в `scripts/build.mjs` и в `<head>` файла `index.html` (canonical, og:url, og:image). Поменять при подключении домена.
- Ссылки на соцсети для окна «Связаться» — `js/contacts.js`.
